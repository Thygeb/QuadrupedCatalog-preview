Notes

  • Unitree sells two configurations side by side on this page, base "H2" and "H2 EDU"; only the base H2 column is used here. H2 EDU differs mainly in dexterous-hand availability, an optional high-power compute module ("Thor"), secondary-development/SDK support, and warranty length (12 vs 8 months). A further, separately named "H2 Plus" is mentioned elsewhere on the site but not detailed on this page.
  • Secondary-development/SDK support is shown as a plain dash ("/") for base H2 versus "YES" for H2 EDU in the producer's own comparison table - the same table convention Unitree uses for other accessory/feature rows on this page (e.g. Dexterous Hand: "/" vs "Dexterous Hand (Multiple Model Options)"). This is read here as base H2 not supporting secondary development; the page also points to a separate "secondary development manual" without quoting it directly.
  • "Arm Maximum Payload" (peak ~15kg, rated ~7kg) is a single-arm manipulation figure, not a figure for what the whole robot can carry.
  • Additional producer-stated figures with no matching field: Calf + Thigh Length 1045mm, Forearm + Upper Arm Length 690mm, construction materials (aircraft-grade aluminum, titanium alloy, high-strength engineering plastics), local air cooling, and WiFi 6 / Bluetooth 5.2.
